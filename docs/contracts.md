# Contracts — every JSON schema

All schemas are strict pydantic models (`extra="forbid"`); the source of
truth is the code.

## `*.fpga.json` — FpgaContract (`src/fpga/contract.py`, schema_version 1)

`name`, `description`, `device {profile, ref}`, `top`,
`sources [{path, language}]`, `libraries [{name, repo, revision, license,
files[]}]`, `clocks [{port, frequency_mhz}]`, `pins [{port, package_pin,
net, io_standard, pull}]`, `build {dir, constraints, bitstream, budget,
pnr_seed}`, `simulations [{id, runner(nvc|iverilog), top, files, expect[],
forbid[], timeout_s, waveform}]`, `formal [{id, mode, top, sources,
parameters, timeout_s}]`, `circuit {connectivity, unused_pins[]}`,
`programmer {board, cable, write_flash}`.

## Device profile (`src/fpga/devices/*.json`, generated)

`id`, `part`, `family (ice40|ecp5|gowin)`, `package`,
`io_voltage_max_v`, `pins [{name, kind(user_io|clock_capable|config|jtag),
caution}]`, `resources {type: budget}`, `nextpnr_args[]`, family fields.
Regenerated by `scripts/extract_device_profiles.py`; never hand-edit.

## Circuit connectivity input (`src/fpga/interchange.py`, schema_version 1)

Written by electrical-circuit-agent: `system: "circuit"`,
`artifact_kind: "circuit_firmware_connectivity"`, `design`, `source`,
`brief_sha256`, `netlist_sha256`, `mcus [{ref, part, pins [{pin, net,
signal_class}]}]`.

## `*.fpga-pinmap.json` — FpgaPinmap (schema_version 1)

`design`, `contract_sha256`, `circuit_sha256` (the circuit export it was
checked against, null when none), `device_ref`, `device_profile`, `part`,
`package`, `io_voltage_max_v`, `pins [{port, package_pin, net,
io_standard, pull}]`, `free_pins[]`.

## `*.fpga-production.json` — FpgaProduction (schema_version 1)

`fpga production` writes it only when the last full gate report passed for
the current contract and the bitstream still has the reported sha256.
`design`, `contract_sha256`, `gate_report_sha256`, `device_ref`,
`device_profile`, `part`, `package`, `bitstream` (relative to the file's
directory), `bitstream_sha256`, `bitstream_bytes`, `target` (`flash` when
`programmer.write_flash`, else volatile `sram`), `tool` (`openFPGALoader`),
`board`, `cable`, `argv` (the loader command, run from the file's
directory).

## `*.fpga-report.json` — GateReport (schema_version 2)

`design`, `scope`, `contract_sha256`, `circuit_sha256`,
`bitstream_sha256`, `profile`, `verdict`, `checks [{id, target, status
(pass|fail|not_applicable), problems[], evidence[]}]`,
`renders [{view, path, sha256}]`.

## `*.fpga-request.json` — FpgaRequest (schema_version 2)

`id`, `design`, `target` (bard|circuit|dashboard|doc|firmware|mech|
prodeng|sim|wire|ux-creator), `risk`, `change`, `rationale`, `nets[]`,
`failing_checks[]`, `contract_sha256`, `inputs [{path, sha256}]` (the
contract is always included), `decision_refs[]` (≥1 event_id from
decisions.jsonl).

## `liaison/*.ux-request.json` — UxRequest (schema_version 2)

`system: "ux-creator"`, `id` (= file stem), `target_agent`, `stage`
(requirements|design|manufacturing_handoff|build|evaluation|revision),
`risk`, `purpose` (≥20 chars), `rationale` (≥20 when risk=high),
`requested_changes[]`, `inputs [{path, sha256}]`,
`expected_deliverables[]`, `acceptance[]`, `depends_on[]`, `created_at`.

## `liaison/*.ux-response.json` — UxResponse (schema_version 2)

`request`, `responder`, `status` (accepted|in_progress|done|rejected|
deferred|needs_info), `reason` (≥20 chars unless accepted/in_progress),
`input_hashes {path: sha256}`, `artifacts [{path, sha256}]`,
`gate_verdicts [{gate, verdict(pass|fail|unknown)}]`, `decision_refs[]`,
`impression_refs[]`, `questions_for_user[]`, `responded_at`.
Validators: `done` forbids fail/unknown verdicts; `needs_info` requires a
question.

## `observations/fpga/*.jsonl` — VRP v1 records (`src/fpga/records.py`)

Envelope: `schema_version 1`, `plugin: "fpga"`, `sequence`, `event_id`
(sha256 of kind+sequence+body), `recorded_at`.

- `decisions.jsonl` — `id`, `stage`, `question`, `principles[]`, ≥2
  `options` with pros/cons, `chosen`, `rationale` (≥200 chars),
  `assumptions[]`, `unknowns[]`, `risks[]`, `revisit_when`, `decided_by`,
  `evidence[]` (path+sha256 or reference).
- `impressions.jsonl` — `stage`, `artifacts [{path, sha256}]`,
  `impression` (≥400 chars, ≥3 distinct sentences).
- `vision-reviews.jsonl` — `image_path`/`image_sha256` or
  `source_event_id`, `model`, `checklist`, `findings [{category,
  severity, note}]`, `impression` (same prose rule).
- `vision-tool-events.jsonl`, `image-observations.jsonl` — hook-written
  observations that vision reviews can cite by `source_event_id`.
- `records-status.json` — last Stop-hook verdict and owed records.

## `plugins/fpga/hooks/records-policy.json`

`plugin`, `records_dir`, `artifact_globs`, `ignore_globs`,
`max_stop_denials` — consumed by the shared `require_records.py` hook.
